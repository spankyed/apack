## Native readiness limitation discovered on review

The current `src/lmdb/adapter.ts` implements `indexesReady` as immediate Promise resolution, although the pinned binding exposes `indexStatus` and `waitForIndexBuilds`. Consequently native adapter-ready times of 1.00–1.28 ms and zero intervening foreground writes **do not measure physical backfill completion**, establish immediate publication or prove absence of background overlap. Final lookup correctness remains proven, but it cannot establish which path served the lookup. The one-sample phase observations are not statistically useful native admission percentiles; one trial has no sample at all. Native whole-run heartbeat p99 is 26.71–27.97 ms (above 16 ms), with 1,666–1,834 commits/s and 22.04–23.04 ms ordered reads.
