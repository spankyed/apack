# Native vector integration slice

Runtime source `de48f5a9242a1b64592a4cc9f173e5e73e2d5ee2` passes all 606 SQLite EARS cases, 135 affected host/storage cases, package builds, EARS types/API, lint and import checks in disposable Linux ARM64 / Node 23.11.1. Two CPUs, 6 GiB RAM, no swap, all capabilities dropped, with actual mode-denial verified. Runtime/native hashes and command receipts are retained. This is affected functional validation, not a newer full Strict or performance/adoption result.

`sqlite/vectors.ts` owns ordinary rebuildable projections, native Hamming owner selection and exact cosine reranking across all selected owners' current chunks. Canonical Float32 values stay authoritative and unchanged. Small, unsupported-dimension and large-K queries stay exact. Foreign-key deletion prevents primary replacement/destruction from orphaning projections. Existing generation backfill projects reused values; explicit rebuild discards projections and reconstructs them without changing logical commit identity. Audit compares projection contents and presence. Query normalization and rare derived safe directions prevent Float32 magnitude overflow/underflow without rewriting canonical bytes. No new native dependency is added.

The 4,600-owner regression uses 300 chunks on the first owner. Exact reranking touches 555 vectors (300 plus 255 other owners), not all 4,899. It filters out an entire unfiltered candidate prefix before K, preserves creation-order ties, excludes trash, supports large K, reads own changes through nested/outer rollback, delivers committed watch updates and cascades destroyed embeddings. Other cases check extreme finite directions, canonical-byte retention, missing/corrupt projection detection and rebuild identity.

Three controls fail for the intended assertions with the source restored after each: forcing exact scan produces 4,899 reranks rather than 555; removing magnitude protection fails numeric results; omitting projection clearing prevents independent corruption detection/repair. These controls run only on private container files. Their logs and command receipts are retained.

Failures are preserved: initial source `69b2376342` had test callback types too narrow for the SQLite unknown-argument API; `6822956968` then passed 89 focused cases but failed plain Node source loading because constructor parameter properties require transpilation. The final ordinary-field constructor passes the exact source-loading regression and all 606 cases. A mutation-harness attempt could not overwrite host-owned copied files with capabilities dropped; atomic replacement of its private scratch files fixed the harness without granting privileges. Refreshing only EARS left captured testing/CLI builds stale, and the API guard refused them. The dependency-directed package build refreshed those inputs before the final passing API/affected checks. No deadline or acceptance assertion was weakened.
